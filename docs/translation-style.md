# 翻訳スタイルガイド（会話）

目標: **Caves of Qud の奇妙で詩的な世界観を残したまま、日本語として一読で頭に入る訳**。

## 基本方針

1. **意味を訳す。語順は日本語に組み替える。** 英語の構文をなぞらない。1文が長くなったら2文に割る。
2. **「辞書にない言葉」で説明しない。** 造語・専門用語は、Qud 固有の言葉（下の用語集）以外は使わない。
   例: implicating evidence を「牽連証拠」としない。
3. **詩・格言・歌は詩として訳す。** 韻は日本語では無理に追わず、行分けと七五調・対句などのリズムで「詩らしさ」を出す。
   原文が1行に詰めて書かれていても、日本語では行分けしてよい。
4. **キャラクターの声を立てる。** 誰が話しても同じ口調、にしない（下の口調表）。
5. **会話の選択肢は短く、言いやすく。** プレイヤーが口にするセリフなので、話し言葉で。
6. **原文にない説明を足さない。** ただし、直訳では意味が通らない言葉遊び・慣用句は、意味が伝わるように言い換える。

## 表記

- 句読点は「、」「。」。疑問符・感嘆符のあとは全角スペース（文末は不要）。
- 三点リーダーは「……」、ダッシュは「――」。
- 引用は「」、作品名は『』。詩の引用は前後を空行で区切り、「」で囲まない（行頭の空白はゲームが消すので字下げはしない）。
- 数字は算用数字。
- `=name=` などの変数は残す。ただし `=player.reflexive=`（yourself 等）や `=pronouns.*=` のように
  **日本語の文中で英単語のまま出てしまう変数は、意味を日本語で書いて変数を外す**。
- `{{W|trade}}` のような色付けタグは、`{{W|` と `}}` を残して中の言葉を訳す（例: `{{W|取引}}`）。
- `~` はランダムに選ばれる別案の区切り。区切りの数を変えない。
- `{{emote|*...*}}` の中は訳す（動作の描写）。

## 共通の会話の方針

- 商人・農夫の口上は短く、職業らしい話しぶりに（銃屋は荒っぽく、帽子屋や仕立て屋はていねい、など）。
- スリンスは覚えたての言葉で、ひらがな多めの片言。
- スナップジョーは、くずれた「いきてのめ」など、日本語でも崩れて聞こえるように。
